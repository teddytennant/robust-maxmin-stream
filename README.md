Streaming robust max-min diversification (Pietracaprina, Pucci, and Zanon, arXiv:2610.01456) in Rust. Build and test with `cargo test`. Departures: GMM's first center is the first input point rather than an arbitrary one; sequential outlier scores use nearest-neighbor distance inside the GMM set; if fewer than z zero-weight coreset points exist, the missing outliers are filled from the smallest weights and the solution is padded to size min(k, n-z) when enough points exist; for delta at least 0.5 the scaling subroutine uses alpha = 8 and m = 10.
